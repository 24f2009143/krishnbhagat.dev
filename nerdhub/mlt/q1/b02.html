📌 3. Cheat Sheet v1 [ADDED]

Saare 8 topics ke core formulas, unki conditions ke saath, ek jagah. Yeh v1 hai: standard theory se bana, code se verify hua, aur PYQ-specific conventions ke liye har jagah "check the question" note hai. Jaise-jaise builds aate hain, yahan ki entries confirm / correct hongi; final cheat sheet B26 mein.

Conventions (is page ke liye): data matrix $X\in\mathbb R^{d\times n}$ — $n$ points, har point ek column $x_i\in\mathbb R^d$. $\mathbf 1_n=\tfrac1n\mathbf{1}\mathbf{1}^T$ (har entry $1/n$). Gram matrix ke eigenvalues ko $\nu$ likha hai taaki mean $\mu$ se confuse na ho.

T1 · Linear Algebra

ItemFormulaCondition / note
Scalar projection of $x$ on $w$$\dfrac{x^Tw}{\|w\|}$Signed length; $w\neq 0$. Unit $w$: simply $x^Tw$.
Vector projection$\dfrac{x^Tw}{w^Tw}\,w$Denominator $w^Tw=\|w\|^2$ (squared!). Unit $w$: $(x^Tw)\,w$.
Residual$r=x-\text{proj}_w(x)$, with $r^Tw=0$Residual is always orthogonal to the direction.
Reconstruction error (squared)$\|x-\text{proj}\|^2=\|x\|^2-\dfrac{(x^Tw)^2}{w^Tw}$Unit $w$: $\|x\|^2-(x^Tw)^2$. Pythagoras se (B3 mein derive).
Squared distance$\|x-y\|^2=\|x\|^2-2x^Ty+\|y\|^2$K-means, kernels, sab jagah.

T2 · PCA

ItemFormulaCondition / note
Centre the data$\mu=\tfrac1n\sum_i x_i,\quad x_i\leftarrow x_i-\mu$Standard PCA pehle centre karta hai (flag F6 yahin se aaya).
Covariance$C=\tfrac1n\sum_i x_ix_i^T=\tfrac1nXX^T$$X$ centred, $d\times d$. $\tfrac1{n-1}$ use ho to saare eigenvalues $\tfrac n{n-1}$ guna; eigenvectors same. Question check karo.
Principal components$Cw=\lambda w,\ \|w\|=1$; PC$_k$ = $k$-th largest $\lambda$ ka eigenvector$C$ symmetric PSD ⇒ $\lambda\ge0$ real, eigenvectors orthogonal. $\pm w$ dono valid (sign ambiguity).
Variance along unit $w$$w^TCw$; maximum $=\lambda_1$ at $w=w_1$$\|w\|=1$ zaroori.
PC coordinate (score)$x^Tw_k$Centred $x$, unit $w_k$.
Total variance / explained ratio$\operatorname{tr}(C)=\sum_j\lambda_j$; ratio $=\dfrac{\sum_{j\le k}\lambda_j}{\sum_j\lambda_j}$Total variance = sab eigenvalues ka sum (flag F7: $\lambda_1\neq$ total).
Rank-$k$ reconstruction$\hat x=\mu+\sum_{j\le k}(x^Tw_j)\,w_j$ ($x$ centred)Average squared error $=\sum_{j>k}\lambda_j$ (jab $C$ mein $\tfrac1n$ ho).
Rank of covariance$\operatorname{rank}(C)\le\min(d,\,n-1)$Centring ke baad points ka sum zero ⇒ ek rank kam. Data $k$-dim subspace mein ho ⇒ $\le k$ non-zero eigenvalues (points poora subspace span karein to exactly $k$); tab $k$ PCs se residue zero.
Dual PCA ($d>n$)$X^TXv=\nu v\ \Rightarrow\ XX^T(Xv)=\nu(Xv)$; PC $w=\dfrac{Xv}{\sqrt\nu}$; eigenvalue of $C$ $=\nu/n$$XX^T$ ($d\times d$) aur $X^TX$ ($n\times n$): non-zero eigenvalues same, eigenvectors alag (size hi alag hai).
Storage after PCA$kd$ (PCs) $+\ kn$ (coefficients) $\ (+\,d$ mean$)$ vs $dn$ originallyCounting convention question se confirm karo (B11).

T3 · Kernels

ItemFormulaCondition / note
Kernel & Gram matrix$k(x,y)=\phi(x)^T\phi(y)$; $K_{ij}=k(x_i,x_j)$Linear kernel: $K=X^TX$.
Valid kernel$K$ symmetric aur PSD (har finite point set ke liye)PSD ⇔ saare eigenvalues $\ge0$ ⇔ $a^TKa\ge0\ \forall a$. Sirf symmetric kaafi nahi.
Standard kernelsPolynomial $(x^Ty+c)^p$, $c\ge0$; Gaussian $\exp\!\big(-\tfrac{\|x-y\|^2}{2\sigma^2}\big)$Gaussian: $k(x,x)=1$ hamesha.
Closure rules$k_1+k_2,\ \ a\,k_1\ (a\ge0),\ \ k_1k_2,\ \ f(x)f(y),\ \ e^{k_1}$ valid$k_1-k_2$ aur $-k_1$ guaranteed nahi. Counterexample: $k_1=xy,\ k_2=2xy$ ⇒ $k_1-k_2=-xy$; single point $x=1$ par Gram matrix $[-1]$, eigenvalue $-1<0$.
Feature maps (2-D)$(x^Ty)^2\to\phi(x)=(x_1^2,\ \sqrt2x_1x_2,\ x_2^2)$
$(x^Ty+1)^2\to(x_1^2,\ x_2^2,\ \sqrt2x_1x_2,\ \sqrt2x_1,\ \sqrt2x_2,\ 1)$		$\phi$ unique nahi — coordinates ka order badalna ya rotate karna bhi chalta hai.
Centred Gram matrix$K^c=K-\mathbf 1_nK-K\mathbf 1_n+\mathbf 1_nK\mathbf 1_n$Kernel PCA se pehle; $\phi$-space mein centring ke barabar.
Kernel PCA$K^cv=\nu v$ (unit $v$); variance $=\nu/n$; training point $i$ ka PC-$k$ score $=\sqrt{\nu_k}\,v_k[i]$Linear kernel lo to ordinary PCA scores aate hain (code se verified).

T4 · K-means

ItemFormula / ruleCondition / note
Objective$F=\sum_{i=1}^n\|x_i-\mu_{z_i}\|^2$Squared distance, grouped by cluster.
Lloyd's algorithmAssign: $z_i=\arg\min_k\|x_i-\mu_k\|^2$. Update: $\mu_k=\tfrac1{|S_k|}\sum_{i\in S_k}x_i$. Repeat jab tak assignments na badlein.Pehle sab points assign karo, tab means update.
Monotonicity$F$ har assign step aur har update step par non-increasingMean squared distance ka minimiser hai (code se verified). Local minimum tak finite steps; init par depend.
K-means++Pehla centre uniform random. Agla: $P(x)=\dfrac{D(x)^2}{\sum_{x'}D(x')^2}$, $D(x)$ = nearest chosen centre se distanceChosen points ke liye $D=0$ ⇒ probability 0. Bank mein "$\propto D$" wale variants bhi hain (flag F2) — question ka wording padho.
Choosing $K$$F$ $K$ badhne par ghatta hai; $K=n$ par $F=0$Isliye sirf $F$ minimise karke $K$ nahi chun sakte (elbow idea).

T5 · Probability, MLE, Bayes

ItemFormulaCondition / note
MLE recipe$\ell(\theta)=\sum_i\log f(x_i;\theta)$; solve $\ell'(\theta)=0$, check $\ell''<0$i.i.d. samples. Likelihood = product, log-likelihood = sum.
Bernoulli($p$)$\hat p=\dfrac{\#\text{ones}}{n}$Likelihood $p^k(1-p)^{n-k}$.
Gaussian$\hat\mu=\bar x,\quad\hat\sigma^2=\tfrac1n\sum_i(x_i-\bar x)^2$MLE variance mein $n$ se divide (biased), $n-1$ se nahi.
Poisson($\lambda$)$\hat\lambda=\bar x$
Exponential (rate $\lambda$)$\hat\lambda=\dfrac{n}{\sum_ix_i}=\dfrac1{\bar x}$pdf $\lambda e^{-\lambda x}$. Agar pdf mean-parametrised ho to formula badlega.
Pareto (known $x_m$)$\hat\alpha=\dfrac{n}{\sum_i\ln(x_i/x_m)}$pdf $\alpha x_m^\alpha/x^{\alpha+1}$; question ka pdf-form B23 mein confirm.
Bayes ruleposterior $\propto$ likelihood $\times$ priorNormalising constant parameter par depend nahi karta.
Beta–BernoulliPrior Beta$(\alpha,\beta)$ + $h$ ones, $t$ zeros ⇒ Beta$(\alpha+h,\ \beta+t)$Example: Beta(3,4) + (15, 35) ⇒ Beta(18, 39).
Beta mean / modemean $\dfrac{\alpha}{\alpha+\beta}$; mode $\dfrac{\alpha-1}{\alpha+\beta-2}$Mode ke liye $\alpha,\beta>1$. MAP = posterior mode. Beta(1,1) prior ⇒ MAP = MLE. Upar wale example mein mean $18/57=0.316$, mode $17/55$.

T6 · Convexity

ItemFormulaCondition / note
Convex function$f(\lambda a+(1-\lambda)b)\le\lambda f(a)+(1-\lambda)f(b)$$\lambda\in[0,1]$. Twice differentiable: convex ⇔ $f''\ge0$.
Jensen (finite form)$f\big(\sum_j\lambda_ja_j\big)\le\sum_j\lambda_jf(a_j)$$f$ convex, $\lambda_j\ge0$, $\sum_j\lambda_j=1$. Concave ho to inequality ulti.
Log version$\log\big(\sum_j\lambda_ja_j\big)\ge\sum_j\lambda_j\log a_j$$\log$ concave; $a_j>0$. EM ka lower bound isi se banta hai.

T7 · GMM + EM

ItemFormulaCondition / note
Mixture density$p(x)=\sum_k\pi_k\,\mathcal N(x\mid\mu_k,\sigma_k^2)$; 1-D: $\mathcal N(x\mid\mu,\sigma^2)=\dfrac1{\sqrt{2\pi\sigma^2}}e^{-(x-\mu)^2/(2\sigma^2)}$$\pi_k\ge0,\ \sum_k\pi_k=1$.
Log-likelihood$\sum_i\log\sum_k\pi_k\,\mathcal N(x_i\mid\mu_k,\sigma_k^2)$Log of a sum ⇒ closed form nahi ⇒ EM.
E-step (responsibility)$\lambda_k^i=\dfrac{\pi_k\,\mathcal N(x_i\mid\mu_k,\sigma_k^2)}{\sum_j\pi_j\,\mathcal N(x_i\mid\mu_j,\sigma_j^2)}$Normalise clusters par; $\sum_k\lambda_k^i=1$ har point $i$ ke liye.
M-step (1-D)$\pi_k=\tfrac1n\sum_i\lambda_k^i,\quad\mu_k=\dfrac{\sum_i\lambda_k^ix_i}{\sum_i\lambda_k^i},\quad\sigma_k^2=\dfrac{\sum_i\lambda_k^i(x_i-\mu_k)^2}{\sum_i\lambda_k^i}$Weighted MLE. $d$-dim spherical covariance ho to $\sigma_k^2$ ke denominator mein extra $d$ (B26 mein confirm).
EM vs LloydLloyd: hard 0/1 assignment, plain mean. EM: soft $\lambda_k^i\in[0,1]$, weighted mean.EM mein log-likelihood kabhi kam nahi hota (code se 30 iterations par verified).

T8 · Regression

ItemFormulaCondition / note
Model & loss$\hat y=w^Tx$; $\ \text{MSE}(w)=\tfrac1n\sum_i(w^Tx_i-y_i)^2$Bias term alag se ho sakta hai — question dekho.
Gradient$\nabla\text{MSE}=\tfrac2nX(X^Tw-y)$$X\in\mathbb R^{d\times n}$, $y\in\mathbb R^n$ (finite differences se verified).
Closed form$XX^Tw=Xy\ \Rightarrow\ w^*=(XX^T)^{-1}Xy$Jab $XX^T$ invertible ho.
Gradient descent$w\leftarrow w-\eta\,\nabla\text{MSE}(w)$MSE convex; quadratic loss par converge hota hai $0<\eta<2/L$ ke liye, $L=\tfrac2n\lambda_{\max}(XX^T)$; $\eta>2/L$ par diverge (code se verified).

⚠️ Top traps (topic-wise)

T1: Vector projection mein $\|w\|^2$ se divide karna hai, $\|w\|$ se nahi. Non-unit $w$ ko unit maan lena.

T2: Centre karna bhoolna (F6). $\tfrac1n$ vs $\tfrac1{n-1}$. $\lambda_1$ aur total variance mix karna (F7). Eigenvector ka sign — $\pm w$ dono sahi.

T3: "Symmetric hai to valid" — galat, PSD chahiye. Do kernels ka difference valid maan lena. Kernel PCA se pehle centring bhoolna.

T4: $D$ vs $D^2$ (F2, F3). Empty cluster ka mean. Points ek ek karke update karna — pehle sab assign, tab update.

T5: MLE variance $\tfrac1n$ se. Beta ka mean aur mode alag cheezein. Posterior mein prior ke $\alpha,\beta$ bhoolna.

T6–T8: Jensen mein weights ka sum 1 aur non-negative; concave par inequality ulti. Responsibility $[0,1]$ mein honi chahiye (F9). Bada $\eta$ diverge karata hai.

Tier 1 · General foundations — quick refresher

Yeh school-level cheezein hain. Har card mein A–E ka chhota roop: core idea, notation, example, common mistake, aur T1 ko iski zaroorat kyun.

G1 · Σ notation, squares, roots

A. $\sum_{j=1}^{d}a_j=a_1+a_2+\cdots+a_d$ — "jodte jao". Square aur root ulte operations hain: $\sqrt{a^2}=|a|$.

B. $(a+b)^2=a^2+2ab+b^2$, $(a-b)^2=a^2-2ab+b^2$.

C. $\sum_{j=1}^{3}j^2=1+4+9=14$. $(3-5)^2=(-2)^2=4$.

D. $(a+b)^2\neq a^2+b^2$; $\sqrt{a^2+b^2}\neq a+b$.

E. Norm ka formula $\sqrt{\sum x_j^2}$ aur $\|x-y\|^2$ ka expansion yahin se aata hai.

G2 · Right triangle

A. Right triangle mein $a^2+b^2=c^2$ (Pythagoras), aur $\cos\theta=\dfrac{\text{adjacent}}{\text{hypotenuse}}$.

B. $\cos0^\circ=1,\ \cos60^\circ=\tfrac12,\ \cos90^\circ=0$, $\cos45^\circ=\tfrac1{\sqrt2}\approx0.707$. Obtuse angle ($>90^\circ$) ka cosine negative.

C. Triangle $(3,4,5)$: $3^2+4^2=25=5^2$, $\cos\theta=\tfrac35=0.6$.

D. Degrees aur radians mix karna; hypotenuse ki jagah koi aur side lena.

E. Dot product ka $\cos\theta$ form aur residual par Pythagoras (P4).

G3 · Coordinates in the plane

A. Point $(a,b)$ = origin se $a$ right, $b$ up ka arrow. Arrow ki length Pythagoras se: $\sqrt{a^2+b^2}$.

B. $(a,b)$ mein pehla number horizontal ($x$-axis) hota hai.

C. $(3,4)$: 3 right, 4 up ⇒ length $\sqrt{9+16}=5$.

D. Order ulta padhna: $(3,4)$ aur $(4,3)$ alag points hain.

E. Is course ki saari figures $2$-D mein hain; $d$ dimensions mein bhi wahi idea chalta hai.

P1 · Vectors, linear combinations, data matrix

A. Core idea

Vector = $d$ numbers ki ordered list. Do tareeke se dekh sakte ho: ek point $d$-dimensional space mein, ya origin se us point tak ka arrow. Vectors par bas do operations hain jinse sab kuch banta hai: scale (har number ko ek constant se guna) aur add (matching positions jodo). Inka mel $c_1a+c_2b$ linear combination kehlata hai.

B. Notation and operations

$$x=\begin{bmatrix}x_1\\x_2\\\vdots\\x_d\end{bmatrix}\in\mathbb R^d,\qquad c\,a+b=\begin{bmatrix}c\,a_1+b_1\\\vdots\\c\,a_d+b_d\end{bmatrix},\qquad \mu=\frac1n\sum_{i=1}^n x_i=\frac1n X\mathbf 1$$
  • $\mathbb R^d$ = $d$ real numbers ke saare vectors. $c$ = koi real number (scalar). $a,b$ = same length ke vectors — alag length ke vectors add nahi hote.
  • $X\in\mathbb R^{d\times n}$ = data matrix: $n$ points, har point ek column $x_i$. $\mathbf 1$ = saari entries 1 wala column vector (length $n$).
  • Notation clash: course mein $x_i$ = $i$-th data point (poora vector). Kisi point ka $j$-th component likhna ho to $x_i[j]$ ya $(x_i)_j$ likhenge. Upar $x_1,\dots,x_d$ sirf ek single vector $x$ ke components hain.

Meaning in words: mean $\mu$ sab points ka linear combination hai, har point ka weight $\tfrac1n$. Notice that "centre karna" = har point se $\mu$ ghatana — iske baad naye points ka sum zero ho jaata hai.

C. Worked examples

Example 1 (simple). $a=(2,-1,3),\ b=(0,4,-2)$. $2a-3b$ nikalo.

Step 1: $2a=(4,-2,6)$. Step 2: $3b=(0,12,-6)$. Step 3: component-wise subtract: $(4-0,\ -2-12,\ 6-(-6))=(4,\,-14,\,12)$.

Example 2 (simple, unknown weights). $(7,-3)=\alpha(1,0)+\beta(2,-1)$ ho to $\alpha,\beta$ kya hain?

Components alag likho: pehla: $\alpha+2\beta=7$; doosra: $0\cdot\alpha-\beta=-3$. Doosre se $\beta=3$. Pehle mein daalo: $\alpha=7-2\cdot3=1$. Check: $1\cdot(1,0)+3\cdot(2,-1)=(1+6,\,0-3)=(7,-3)$ ✓.

✍️ Example 3 (exam-level) — Try first

$X=\begin{bmatrix}1&3&-1\\2&0&4\end{bmatrix}$. (i) $d$ aur $n$ kya hain aur points kaunse hain? (ii) Mean $\mu$ nikalo. (iii) Centred points likho aur check karo ki unka sum zero hai.

Pehle khud karo, phir confidence socho: S (Sure) / U (Unsure) / G (Guess).

Show solution

(i) $X$ ki size $2\times3$ hai, $d\times n$ convention mein $d=2$ (features), $n=3$ (points). Columns: $x_1=(1,2),\ x_2=(3,0),\ x_3=(-1,4)$.

(ii) Sum $=(1+3+(-1),\ 2+0+4)=(3,6)$. Mean $\mu=\tfrac13(3,6)=(1,2)$.

(iii) $x_1-\mu=(0,0)$; $x_2-\mu=(2,-2)$; $x_3-\mu=(-2,2)$. Sum: $(0+2-2,\ 0-2+2)=(0,0)$ ✓.

Yeh data PCA ke prerequisites (B4) mein dobara aayega.

Non-example: $(1,2)+(3,4,5)$ defined nahi hai — lengths 2 aur 3 alag hain. $2\times3$ matrix ko "3 dimensions ke 2 points" padhna bhi galat hai: woh 2-D ke 3 points hain.

D. Common mistakes

  • $x_1$ ko "pehla component" aur "pehla data point" dono samajh lena — course mein $x_i$ point hai.
  • Columns ki jagah rows padhna ($X$ is $d\times n$).
  • Scaling mein sirf pehla component guna karna.
  • Centring ke baad sum zero check karna bhool jaana — yeh sabse tez sanity check hai.

E. Why PCA / T1 needs this — ML bridge

Q: Data matrix mein points columns kyun hain?
A: Isse $XX^T=\sum_ix_ix_i^T$ ($d\times d$, features × features) aur $X^TX$ ($n\times n$, entry $(i,j)=x_i^Tx_j$, points × points) dono seedhe milte hain. PCA pehle wale ko use karta hai, dual PCA aur kernels doosre ko.

Q: Mean ko linear combination ki tarah kyun dekhein?
A: Kyunki centring ek linear operation ban jaata hai, aur K-means ka mean update bhi wahi hai — bas weights $\tfrac1{|S_k|}$ hain, $\tfrac1n$ nahi.

P2 · Dot product

A. Core idea

Dot product do vectors ko ek number mein badalta hai: matching components ko guna karo, phir jodo. Geometrically yeh batata hai ki ek vector doosre ki direction mein kitna "failta" hai: positive = lagbhag same direction, zero = perpendicular, negative = ulti direction.

B. Notation and operations

$$x^Tw=\sum_{j=1}^{d}x_j\,w_j$$
  • $x,w\in\mathbb R^d$ — same length $d$. $x^T$ = $x$ ko row ki tarah likhna. Result ek scalar (number) hai.
  • Dusre naam: $x\cdot w$, $\langle x,w\rangle$ — sab same cheez.
  • Properties: (1) symmetric: $x^Tw=w^Tx$. (2) linear: $(\alpha x+\beta y)^Tw=\alpha\,x^Tw+\beta\,y^Tw$. (3) $x^Tx=\sum_jx_j^2\ge0$, aur $=0$ tabhi jab $x=0$.

Notice that linearity ka matlab: kisi linear combination ke saath dot product, alag-alag dot products ka linear combination hota hai — Example 2 mein yehi use hoga. Important insight: $x^Tx$ vector ki "length ka square" hai — isi se norm (P3) bana hai.

Example 1 (simple). $x=(3,4,-1),\ w=(2,0,5)$.

$x^Tw=3\cdot2+4\cdot0+(-1)\cdot5=6+0-5=1$.

✍️ Example 2 (exam-level) — Try first

$x=(1,2),\ w=(3,-1),\ y=(-2,4)$. $x^T(2w-y)$ do tareeke se nikalo: (a) pehle $2w-y$ banake, (b) linearity se.

Confidence: S / U / G?

Show solution

(a) Direct. $2w=(6,-2)$; $2w-y=(6-(-2),\ -2-4)=(8,-6)$. Phir $x^T(8,-6)=1\cdot8+2\cdot(-6)=8-12=-4$.

(b) Linearity. $x^T(2w-y)=2\,(x^Tw)-x^Ty$. $x^Tw=1\cdot3+2\cdot(-1)=1$ aur $x^Ty=1\cdot(-2)+2\cdot4=6$. Isliye $2\cdot1-6=-4$ ✓ — dono tareeke same.

Non-example: $x\in\mathbb R^3,\ w\in\mathbb R^2$ — $x^Tw$ defined nahi (lengths alag). Aur $xw^T$ ek number nahi, matrix hai.

D. Common mistakes

  • Answer ko vector samajhna — dot product scalar hai.
  • Negative components ke saath sign galti ($(-1)\cdot5=-5$).
  • $x^Tw$ aur $xw^T$ mix karna.
  • "$x^Tw=0\Rightarrow x=0$ ya $w=0$" — galat; nonzero perpendicular vectors ka dot bhi 0 hota hai.

E. Why PCA / T1 needs this — ML bridge

Q: PCA mein point ka "coordinate" kya hota hai?
A: Point $x$ ka PC $w_k$ par coordinate $x^Tw_k$ ($w_k$ unit norm, $x$ centred). B1 ke pattern table ka "Point ka PC coordinates $(a,b)$" pattern (5 sets) seedha do dot products hai.

Q: Kernel ka dot product se kya rishta hai?
A: $k(x,y)=\phi(x)^T\phi(y)$ — kernel feature space mein ek dot product hai. Gram matrix ki har entry ek dot product hoti hai.

P3 · Norm, unit vector, distance

A. Core idea

Norm = vector ki length: khud se dot karo, phir square root lo. Do points ke beech distance = unke difference vector ki length. Unit vector = length 1 wala vector; kisi bhi nonzero vector ko apni length se divide karo to direction bachti hai aur length 1 ho jaati hai.

B. Notation and operations

$$\|x\|=\sqrt{x^Tx}=\sqrt{\sum_{j=1}^d x_j^2},\qquad \|x-y\|^2=\|x\|^2-2\,x^Ty+\|y\|^2,\qquad u=\frac{w}{\|w\|}$$
  • $\|x\|$ = $x$ ki length; $\|x-y\|$ = points $x,y$ ke beech distance; $u$ = $w$ ki direction mein unit vector ($w\neq0$).
  • Properties: $\|\alpha x\|=|\alpha|\,\|x\|$; $\|x\|=0\iff x=0$; triangle inequality $\|x+y\|\le\|x\|+\|y\|$.

Expansion kaise bana (koi step skip nahi): $\|x-y\|^2=(x-y)^T(x-y)=x^Tx-x^Ty-y^Tx+y^Ty$. Dot product symmetric hai ($y^Tx=x^Ty$), isliye middle terms mil kar $-2x^Ty$ ho jaate hain.

Notice that yeh $(a-b)^2=a^2-2ab+b^2$ ka hi vector version hai. Important insight: distance ka square sirf do squared lengths aur ek dot product se bana — yahi wajah hai ki dot products (Gram matrix) se saari distances nikal sakte hain. This is why kernels mein $\|x-y\|^2$ ko $k(x,x)-2k(x,y)+k(y,y)$ likh sakte hain (B13+).

C. Worked examples

Example 1 (simple). $x=(3,4)$: $\|x\|=\sqrt{9+16}=5$. Unit vector $u=\tfrac15(3,4)=(0.6,\,0.8)$. Check: $\|u\|=\sqrt{0.36+0.64}=1$ ✓.

Example 2 (simple, 3-D). $w=(1,2,2)$: $\|w\|=\sqrt{1+4+4}=3$. $u=(\tfrac13,\tfrac23,\tfrac23)$. Check: $\tfrac19+\tfrac49+\tfrac49=1$ ✓.

✍️ Example 3 (exam-level) — Try first

$x=(2,-1),\ y=(5,3)$. $\|x-y\|^2$ do tareeke se nikalo: (a) seedha difference se, (b) expansion se. Dono match hone chahiye.

Confidence: S / U / G?

Show solution

(a) Direct. $x-y=(2-5,\ -1-3)=(-3,-4)$. $\|x-y\|^2=9+16=25$.

(b) Expansion. $\|x\|^2=4+1=5$; $\|y\|^2=25+9=34$; $x^Ty=2\cdot5+(-1)\cdot3=10-3=7$. Isliye $5-2\cdot7+34=5-14+34=25$ ✓.

Non-example: $\|x+y\|=\|x\|+\|y\|$ hamesha sach nahi. $x=(3,0),\ y=(0,4)$: $\|x+y\|=\|(3,4)\|=5$ par $\|x\|+\|y\|=3+4=7$. Barabari tabhi jab dono ek hi direction mein hon.

D. Common mistakes

  • $\|x\|^2$ aur $\|x\|$ mix karna (square root bhoolna ya bahut jaldi lena).
  • $\|x-y\|^2=\|x\|^2-\|y\|^2$ likhna — beech ka $-2x^Ty$ gayab.
  • Normalise karte waqt $\|w\|^2$ se divide karna ya sirf ek component divide karna.
  • Zero vector ko normalise karne ki koshish (length 0 se divide).

E. Why PCA / T1 needs this — ML bridge

Q: PCA mein $\|w\|=1$ kyun maangte hain?
A: Direction ke liye sirf disha matter karti hai. $w$ ko 2 se guna to coordinate $x^Tw$ do guna aur variance $w^TCw$ chaar guna ho jaata hai — bina constraint ke "maximum variance" infinite hota. Unit norm scale fix kar deta hai.

Q: K-means mein norm kahan aata hai?
A: Objective $F=\sum_i\|x_i-\mu_{z_i}\|^2$ squared distance hai, aur upar wala expansion hi B19 mein dikhayega ki cluster ka mean best centre kyun hai.

P4 · Angle, cos θ, orthogonality

A. Core idea

Dot product ka ek geometric chehra hai: $x^Tw=\|x\|\,\|w\|\cos\theta$. Isse dot product se angle nikal sakte hain, aur dot $=0$ ka matlab angle $90^\circ$ — vectors perpendicular (orthogonal). Orthogonal vectors par Pythagoras kaam karta hai.

B. Notation and operations

$$x^Tw=\|x\|\,\|w\|\cos\theta\quad\Longleftrightarrow\quad\cos\theta=\frac{x^Tw}{\|x\|\,\|w\|},\qquad \|a+b\|^2=\|a\|^2+\|b\|^2+2\,a^Tb$$
  • $\theta\in[0^\circ,180^\circ]$ = do nonzero vectors $x,w$ ke beech ka angle.
  • Orthogonal: $x\perp w\iff x^Tw=0$. Orthonormal = orthogonal aur dono unit-length.
  • $a^Tb=0$ ho to cross term $2a^Tb$ gayab ⇒ $\|a+b\|^2=\|a\|^2+\|b\|^2$ (Pythagoras).

Notice that $\cos\theta\in[-1,1]$, isliye hamesha $|x^Tw|\le\|x\|\,\|w\|$ (Cauchy–Schwarz). Aur $\|a+b\|^2$ ka expansion P3 wale expansion se hi nikalta hai ($b$ ko $-b$ se badlo).

Example 1 (simple). $x=(1,2),\ w=(2,-1)$: $x^Tw=1\cdot2+2\cdot(-1)=0$ ⇒ orthogonal.

Example 2 (simple, angle). $x=(1,1),\ w=(1,0)$: $x^Tw=1$, $\|x\|=\sqrt2$, $\|w\|=1$. $\cos\theta=\dfrac{1}{\sqrt2\cdot1}\approx0.7071\Rightarrow\theta=45^\circ$.

Confidence: S / U / G?

Example 4 (Pythagoras, tricky). $a=(1,0),\ b=(1,1)$. $a+b=(2,1)$ ⇒ $\|a+b\|^2=4+1=5$. Lekin $\|a\|^2+\|b\|^2=1+2=3$. Farak $=2$ $=2a^Tb=2\cdot1$ ✓ — yahan $a,b$ orthogonal nahi hain ($a^Tb=1\neq0$), isliye seedha jodna galat tha.

D. Common mistakes

  • $\cos$ nikalte waqt calculator degree / radian mode mix karna.
  • "Dot $=0$" ko "vector zero hai" samajhna.
  • Pythagoras (squared lengths ka sum) bina orthogonality check kiye lagana (Example 4).
  • Nonzero orthogonal vectors independent hote hain, par independent vectors orthogonal ho — zaroori nahi ($(1,0)$ aur $(1,1)$ independent hain, orthogonal nahi).

E. Why PCA / T1 needs this — ML bridge

Q: Projection ka residual direction ke perpendicular kyun hota hai?
A: Direction $w$ ki line par $x$ ka sabse paas wala point woh hai jahan baaki bacha hissa (residual) $w$ ke perpendicular ho. Tab Pythagoras lagta hai: $\|x\|^2=\|\text{proj}\|^2+\|\text{residual}\|^2$, aur unit $w$ ke liye $\|\text{proj}\|^2=(x^Tw)^2$. Yani reconstruction error $=\|x\|^2-(x^Tw)^2$ — preview; poori derivation B3 mein.

Q: PCA ke principal components orthogonal kyun hote hain?
A: Symmetric matrix ke alag eigenvalues wale eigenvectors orthogonal hote hain (proof B4 / B7 mein). Isse PC coordinates independent axes ki tarah behave karte hain.

P5 · Matrix–vector product, transpose, outer product

A. Core idea

Matrix = vectors ko transform karne wali machine. $Ax$ ka matlab: $A$ ke columns ka linear combination, jahan weights $x$ ke components hain. Transpose rows aur columns ulta karta hai. Outer product $xw^T$ ek column aur ek row se poori matrix banata hai.

B. Notation and operations

$$(Ax)_i=\sum_{j}A_{ij}\,x_j,\qquad Ax=\sum_j x_j\,A_{:,j},\qquad (xw^T)_{ij}=x_i\,w_j,\qquad (AB)^T=B^TA^T$$
  • $A\in\mathbb R^{m\times n}$, $x\in\mathbb R^n$ ⇒ $Ax\in\mathbb R^m$. Size rule: $(m\times n)(n\times p)=(m\times p)$ — beech wale $n$ match hone chahiye.
  • $A_{:,j}$ = $A$ ka $j$-th column. Transpose: $(A^T)_{ij}=A_{ji}$. Symmetric matrix: $A^T=A$.
  • Do key identities: $(ww^T)x=w\,(w^Tx)$ — "$w$ ka scalar multiple" aur $XX^T=\sum_ix_ix_i^T$, $(X^TX)_{ij}=x_i^Tx_j$.

Notice that $(ww^T)x=w(w^Tx)$: matrix $ww^T$ kisi bhi $x$ ko $w$ ki line par la deta hai — yeh projection ka matrix-form hai (B3).

C. Worked examples

Example 1 (simple). $A=\begin{bmatrix}1&2\\0&-1\\3&1\end{bmatrix}$ ($3\times2$), $x=(2,-1)$.

Row view: $(1\cdot2+2\cdot(-1),\ 0\cdot2+(-1)(-1),\ 3\cdot2+1\cdot(-1))=(0,\,1,\,5)$.

Column view: $2\,(1,0,3)-1\,(2,-1,1)=(2,0,6)-(2,-1,1)=(0,1,5)$ ✓ — dono same.

Example 2 (outer product). $w=(1,2)$: $ww^T=\begin{bmatrix}1\cdot1&1\cdot2\\2\cdot1&2\cdot2\end{bmatrix}=\begin{bmatrix}1&2\\2&4\end{bmatrix}$. $x=(3,1)$ par lagao: $(1\cdot3+2\cdot1,\ 2\cdot3+4\cdot1)=(5,10)$. Check: $w^Tx=3+2=5$ aur $5\cdot w=(5,10)$ ✓.

✍️ Example 3 (exam-level) — Try first

$X=\begin{bmatrix}1&3&-1\\2&0&4\end{bmatrix}$ ($d=2,\ n=3$). (i) $XX^T$ aur $X^TX$ ki sizes batao aur dono compute karo. (ii) Dono ke traces compare karo. (iii) Kya dono ke eigenvalues same ho sakte hain? Kyun?

Confidence: S / U / G?

Show solution

(i) Sizes. $XX^T$: $(2\times3)(3\times2)=2\times2$. $X^TX$: $(3\times2)(2\times3)=3\times3$.

Columns: $x_1=(1,2),\ x_2=(3,0),\ x_3=(-1,4)$.

$XX^T=\sum_ix_ix_i^T$: $x_1x_1^T=\begin{bmatrix}1&2\\2&4\end{bmatrix}$, $x_2x_2^T=\begin{bmatrix}9&0\\0&0\end{bmatrix}$, $x_3x_3^T=\begin{bmatrix}1&-4\\-4&16\end{bmatrix}$. Jodne par $XX^T=\begin{bmatrix}1+9+1&2+0-4\\2+0-4&4+0+16\end{bmatrix}=\begin{bmatrix}11&-2\\-2&20\end{bmatrix}$.

$X^TX$ (entry $x_i^Tx_j$): $x_1^Tx_1=5,\ x_1^Tx_2=3,\ x_1^Tx_3=-1+8=7,\ x_2^Tx_2=9,\ x_2^Tx_3=-3+0=-3,\ x_3^Tx_3=1+16=17$. Isliye $X^TX=\begin{bmatrix}5&3&7\\3&9&-3\\7&-3&17\end{bmatrix}$.

(ii) Traces. $\operatorname{tr}(XX^T)=11+20=31$; $\operatorname{tr}(X^TX)=5+9+17=31$ — barabar (dono $\sum_i\|x_i\|^2$ hain).

(iii) Eigenvalues. $XX^T$ ka characteristic polynomial: $\lambda^2-31\lambda+(11\cdot20-(-2)^2)=\lambda^2-31\lambda+216$. Discriminant $=961-864=97$, isliye $\lambda=\dfrac{31\pm\sqrt{97}}{2}\approx20.424,\ 10.576$. $X^TX$ ($3\times3$) ke eigenvalues code se: $20.424,\ 10.576$ aur $0$. Yaani non-zero eigenvalues same, par $X^TX$ mein ek extra $0$ — kyunki us ki size bhi alag hai aur rank sirf $2$ hai. Eigenvectors same ho hi nahi sakte: ek $\mathbb R^2$ mein, doosra $\mathbb R^3$ mein.

Non-example: $A$ ($3\times2$) ko $x\in\mathbb R^3$ se multiply nahi kar sakte (beech ke sizes $2\neq3$). Aur $(AB)^T=A^TB^T$ galat hai — sahi $B^TA^T$ hai.

Deeper: $ww^T$ ko dobara lagane par kya hota hai?

$w=(1,2)$ ke liye $ww^T=\begin{bmatrix}1&2\\2&4\end{bmatrix}$. Square karo: $(ww^T)(ww^T)=w\,(w^Tw)\,w^T=5\,ww^T$ — kyunki $w^Tw=1+4=5$. Agar $w$ unit ho ($w^Tw=1$) to $(ww^T)^2=ww^T$: ek baar line par girne ke baad dobara girne se kuch nahi badalta. Yeh B3 mein projection matrix ki pehchaan banegi.

Bonus: $\operatorname{tr}(ww^T)=\sum_jw_j^2=\|w\|^2$ (self-check Q8).

D. Common mistakes

  • Size mismatch — multiply karne se pehle $(m\times n)(n\times p)$ check karo.
  • $x^Tw$ (number) aur $xw^T$ (matrix) mix karna.
  • $(AB)^T=A^TB^T$ likhna.
  • $X$ ko $n\times d$ padh lena — is course mein $d\times n$.
  • $XX^T$ aur $X^TX$ ko same size / same eigenvectors maan lena.

E. Why PCA / T1 needs this — ML bridge

Q: Covariance matrix, matrix ki bhasha mein, kya hai?
A: $C=\tfrac1n\sum_ix_ix_i^T=\tfrac1nXX^T$ (centred $X$): har point ke outer product ka average. Entry $(a,b)$ = features $a$ aur $b$ ke products ka average.

Q: "$XX^T$ aur $X^TX$ ke eigenvectors same hain?" ka PYQ pattern kyun baar-baar aata hai?
A: B1 ke pattern table mein yeh 3 baar hai (jawab: No). Wajah Example 3 mein dikhi: sizes alag ($d\times d$ vs $n\times n$), isliye eigenvectors alag lengths ke; sirf non-zero eigenvalues same. Dual PCA (B12) isi relation par bana hai.
